# IoT & Cloud Computing Course: Azure and AWS

## Course Overview
This course provides an in-depth understanding of IoT and Cloud Computing using Microsoft Azure, with an AWS option for selected exercises. It covers the fundamentals, architecture, and practical applications of cloud services in IoT solutions.

## Course Objectives
- Understand the basics of IoT and Cloud Computing.
- Docker and Azure Container Instances
- Learn about Azure IoT Hub and its components.
- Explore Azure services like Azure Functions, and Azure Cosmos DB.
- Store IoT data in relational (PostgreSQL) and NoSQL databases.
- Develop and deploy IoT solutions using Azure.
- Compare Azure services with their AWS counterparts.

## Prerequisites
- Basic knowledge of programming (Python).
- Familiarity with cloud computing concepts.

## Azure or AWS

Every exercise is written for **Azure**. Exercises that also have an **AWS** version keep it in an `aws/` subfolder (for example [2-iaas/aws](2-iaas/aws/readme.md)), linked at the top of the Azure readme. The AWS versions are written for a personal AWS account and use Free Tier eligible services where possible; an AWS Academy Learner Lab account also works, with the limits listed in [1-cloud-account/aws](1-cloud-account/aws/readme.md), which explains how to set up either one.

Exercises with an AWS version:
- 1 - Cloud account
- 2 - IaaS (Virtual Machine / EC2)
- 3 - IaaS scale set (Virtual Machine Scale Set / Auto Scaling group)
- 4 - Containers (Container Instances / ECS on Fargate)
- 5 - PaaS web app (App Service / App Runner or Elastic Beanstalk)
- 6 - IoT over MQTT (IoT Hub / IoT Core)
- 7 - PostgreSQL database (Azure Database for PostgreSQL / Amazon RDS)
- 8 - Static website (Blob Storage / Amazon S3)
- 9 - NoSQL database (Cosmos DB / Amazon DynamoDB)
- 10 - Serverless functions and an AI agent (Azure Functions + Azure OpenAI in Foundry / AWS Lambda + Amazon Bedrock)
- 11 - Serverless IoT platform (IoT Hub + Stream Analytics + Cosmos DB + Functions / IoT Core + IoT rule + DynamoDB + Lambda + API Gateway)
