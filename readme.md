# IoT & Cloud Computing Course: Azure and AWS

## Course Overview
This course provides an in-depth understanding of IoT and Cloud Computing using Microsoft Azure, with an AWS option for selected exercises. It covers the fundamentals, architecture, and practical applications of cloud services in IoT solutions.

## Course Objectives
- Understand the basics of IoT and Cloud Computing.
- Docker and Azure Container Instances
- Learn about Azure IoT Hub and its components.
- Explore Azure services like Azure Functions, and Azure Cosmos DB.
- Develop and deploy IoT solutions using Azure.
- Compare Azure services with their AWS counterparts.

## Prerequisites
- Basic knowledge of programming (Python).
- Familiarity with cloud computing concepts.

## Azure or AWS

Every exercise is written for **Azure**. Exercises that also have an **AWS** version keep it in an `aws/` subfolder (for example [2-iaas/aws](2-iaas/aws/readme.md)), linked at the top of the Azure readme. The AWS versions use a personal AWS account and only Free Tier eligible services - see [1-cloud-account/aws](1-cloud-account/aws/readme.md) to set one up.

Exercises with an AWS version:
- 1 - Cloud account
- 2 - IaaS (Virtual Machine / EC2)
